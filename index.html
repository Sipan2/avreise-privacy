Hvilke data samler vi inn?

Avreise samler inn følgende data:

  • Posisjon (GPS) – brukes til å beregne avgangstid fra der du befinner deg til Oslo Lufthavn Gardermoen. Posisjonen lagres aldri og sendes ikke til noen server.
  • Hjemadresse – hvis du velger å lagre en hjemadresse, lagres gatenavn og koordinater lokalt på enheten din (UserDefaults). Dataen forlater aldri enheten.

Deler vi data med tredjeparter?

Appen bruker Entur Journey Planner API for rutedata. Koordinatene dine sendes til Entur for å hente kollektivruter. Entur er et norsk offentlig selskap (AS). Se Enturs personvernerklæring.

Appen bruker Avinors åpne API for flginformasjon. Ingen persondata sendes til Avinor.

Vi deler ikke data med reklameselskaper, analyseverktøy eller andre tredjeparter.

Analyse og sporing

Appen inneholder ingen analyse, sporing, annonsering eller tredjeparts SDK-er.

Lagring

All data (hjemadresse, reiseanbefaling) lagres utelukkende lokalt på enheten din og slettes automatisk hvis du avinstallerer appen.

Dine rettigheter

Du kan når som helst slette lagret hjemadresse i appen. Siden vi ikke lagrer noen data eksternt, finnes det ingen data å be om innsyn i eller sletting av hos oss.

Endringer

Eventuelle endringer i denne erklæringen vil gjenspeiles på denne siden med oppdatert dato.
